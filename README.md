# Debopriya Bose - Portfolio Website

A modern, responsive portfolio website showcasing skills, projects, and professional connections.

## 🌟 Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with glassmorphism effects and smooth animations
- **Projects Showcase**: Two distinct categories for deployed and repository projects
- **Interactive Elements**: Smooth scrolling, typing effects, and hover animations
- **Contact Form**: Local storage-based contact form for visitor messages
- **Resume Viewer**: Built-in PDF resume viewer modal

## 🚀 Deployment

This portfolio is designed for seamless deployment on **Cloudflare Pages**:

1. Push your code to GitHub
2. Connect your repository to Cloudflare Pages
3. Deploy with default settings (no build command needed)
4. Your portfolio will be live instantly!
